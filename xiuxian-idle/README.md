## 快速开始

1. 直接用浏览器打开 `index.html` 即可开始游戏
2. 无需安装任何依赖，纯前端运行
3. 游戏自动存档，关闭浏览器后再次打开可继续

### 运行环境

- 任意现代浏览器（Chrome / Edge / Firefox / Safari）
- 无需联网（纯本地运行）
- 支持 PC 端和平板端

## 核心玩法循环

```
挂机自动产出修为/灵石
        ↓
用灵石升级功法 → 提升产出效率
        ↓
修为攒满 → 突破境界 → 解锁新内容
        ↓
历练探险 → 获得法宝/丹药/额外资源
        ↓
装备法宝 → 进一步提升产出
        ↓
使用丹药 → 临时加速或立即获得资源
        ↓
达成成就 → 获得道韵（永久加成）
        ↓
转世重修 → 重置进度换更多道韵 → 循环加速
```

## 系统详解

### 境界系统

游戏共有 **9大境界**，每个境界分为 **9层**，共81个阶段。

| 境界 | 突破基础修为 | 修为加成 | 灵石加成 |
|------|-------------|---------|---------|
| 练气期 | 100 | +0% | +0% |
| 筑基期 | 1,000 | +50% | +30% |
| 金丹期 | 10,000 | +150% | +100% |
| 元婴期 | 100,000 | +400% | +300% |
| 化神期 | 1,000,000 | +1000% | +800% |
| 炼虚期 | 10,000,000 | +2500% | +2000% |
| 合体期 | 100,000,000 | +6000% | +5000% |
| 大乘期 | 1,000,000,000 | +15000% | +12000% |
| 渡劫期 | 10,000,000,000 | +40000% | +30000% |

- 每层突破所需修为 = 基础修为 × 境界倍率^(层数-1)
- 境界倍率：练气1.5 → 渡劫2.3，逐层递增
- 突破到大境界时会触发弹窗庆祝和屏幕闪光特效

### 挂机产出

两种核心资源自动产出：

- **修为**：用于突破境界，基础产出 1.5/秒
- **灵石**：用于购买功法、丹药、招募弟子，基础产出 0.8/秒

产出速度受以下因素加成：
- 功法升级（固定数值加成）
- 境界加成（百分比加成）
- 弟子加成（百分比加成）
- 法宝加成（固定数值加成）
- 道韵加成（百分比加成，每点+1%）
- 丹药Buff（临时百分比加成）

### 功法升级

共 **10种功法**，消耗灵石升级，提供固定数值的产出加成。

| 功法 | 类型 | 解锁境界 | 基础效果 |
|------|------|---------|---------|
| 基础吐纳术 | 修为 | 练气期 | +0.8/秒 |
| 聚灵阵 | 灵石 | 练气期 | +0.5/秒 |
| 龟息吐纳法 | 修为 | 筑基期 | +4/秒 |
| 灵田开垦 | 灵石 | 筑基期 | +3/秒 |
| 心法要诀 | 全属性 | 筑基期 | +5/秒 |
| 炼丹之术 | 全属性 | 金丹期 | +10/秒 |
| 炼器之术 | 全属性 | 金丹期 | +25/秒 |
| 周天星斗阵 | 修为 | 元婴期 | +120/秒 |
| 御剑之术 | 灵石 | 元婴期 | +80/秒 |
| 悟道心得 | 全属性 | 化神期 | +350/秒 |

- 每级费用 = 基础费用 × 费用倍率^等级
- 每级效果 = 基础效果 × 效果倍率^(等级-1) × 等级
- 每种功法有最高等级限制（60-200级不等）

### 弟子系统

- 消耗灵石招募弟子，每名弟子提供：
  - +5% 修为产出
  - +3% 灵石产出
- 招募费用递增：50灵石 × 1.3^已招募数
- 最多招募100名弟子

### 丹药系统

共 **7种丹药**，分为临时Buff和立即获得两类。

#### 临时Buff类

| 丹药 | 效果 | 持续时间 | 价格 |
|------|------|---------|------|
| 聚气丹 | 修为+100% | 5分钟 | 100灵石 |
| 聚灵符 | 灵石+100% | 5分钟 | 100灵石 |
| 双倍修为丹 | 修为+200% | 3分钟 | 300灵石 |
| 聚财符 | 灵石+200% | 3分钟 | 300灵石 |
| 混元丹 | 修为+80% 灵石+80% | 10分钟 | 800灵石 |

#### 立即获得类

| 丹药 | 效果 | 价格 |
|------|------|------|
| 悟道丹 | 立即获得30秒修为产出 | 80灵石 |
| 点石成金符 | 立即获得60秒灵石产出 | 80灵石 |

- 丹药可囤积，随时使用
- 活跃Buff在左侧面板显示剩余时间
- 同种Buff可叠加（持续时间叠加）

### 法宝系统

#### 法宝品质

共 **5档品质**，影响法宝基础属性：

| 品质 | 属性倍率 | 掉落权重 |
|------|---------|---------|
| 凡品 | ×1.0 | 50% |
| 良品 | ×1.5 | 30% |
| 上品 | ×2.5 | 14% |
| 极品 | ×4.0 | 5% |
| 仙品 | ×7.0 | 1% |

#### 法宝类型

共 **6种类型**，各有不同加成方向：

| 类型 | 加成方向 | 基础值 |
|------|---------|--------|
| 飞剑 | 修为 | 5 |
| 护盾 | 灵石 | 3 |
| 宝镜 | 全属性 | 2 |
| 法印 | 修为 | 8 |
| 铜钟 | 灵石 | 5 |
| 宝塔 | 全属性 | 4 |

#### 装备与套装

- 共 **3个装备槽位**
- 点击背包中的法宝自动装备到空槽位
- 点击已装备法宝可卸下
- **套装效果**：同类型法宝装备2件+10%，3件+25%
- 右键点击背包法宝可分解换取灵石

#### 获取途径

- 历练探险随机掉落（几率10%-55%）
- 历练完成时有几率获得

### 历练系统

共 **5个历练地点**，按境界解锁，派遣后需等待指定时间。

| 地点 | 时长 | 解锁境界 | 修为奖励 | 灵石奖励 | 法宝掉率 | 丹药掉率 |
|------|------|---------|---------|---------|---------|---------|
| 迷雾森林 | 1分钟 | 练气期 | 80 | 50 | 15% | 10% |
| 幽暗洞窟 | 3分钟 | 筑基期 | 400 | 280 | 25% | 15% |
| 灵脉山脉 | 5分钟 | 金丹期 | 2,000 | 1,400 | 35% | 20% |
| 上古遗迹 | 10分钟 | 元婴期 | 10,000 | 7,000 | 45% | 25% |
| 虚空裂隙 | 20分钟 | 化神期 | 60,000 | 40,000 | 55% | 35% |

- 奖励随当前境界提升（每提升一大境界+50%）
- 历练期间无法再次出发
- 离线期间历练会自动完成结算
- 完成时有几率触发**奇遇事件**

#### 奇遇事件

历练完成时随机触发，影响最终收益：

| 事件 | 修为倍率 | 灵石倍率 | 触发率 |
|------|---------|---------|--------|
| 发现灵泉 | ×2.0 | ×1.0 | 8% |
| 遇到散修 | ×1.0 | ×2.5 | 8% |
| 上古洞府 | ×2.0 | ×2.0 | 4% |
| 妖兽袭击 | ×0.6 | ×0.6 | 10% |
| 仙人指路 | ×1.5 | ×1.5 | 5% |

### 灵宠系统

- 可获得多种灵宠，出战后提供产出加成
- 灵宠类型：火狐（修为）、玄龟（灵石）、仙鹤（全属性）、白虎（高修为）、青龙（高全属性）
- 5档品质：凡品→良品→上品→极品→仙品，影响基础属性和等级上限
- 灵宠可升级（消耗灵石），每级+10%属性
- 好感度系统：喂养提升好感度，影响属性发挥（50%~150%）
- 只能同时出战1只灵宠
- 获取途径：秘境掉落、随机事件、云游商人

### 秘境挑战

- 5个秘境，按境界解锁，消耗灵石挑战
- 基于玩家战力计算成功率（最高95%）
- 战力 = 境界 + 功法等级 + 弟子 + 法宝 + 灵宠 + 道韵
- 成功获得：修为、灵石、高品质法宝、灵宠、天赋点
- 失败损失少量修为
- 每个秘境有独立冷却时间（2~15分钟）

| 秘境 | 解锁境界 | 推荐战力 | 消耗 | 冷却 |
|------|---------|---------|------|------|
| 妖兽森林 | 练气期 | 50 | 100灵石 | 2分钟 |
| 骸骨洞窟 | 筑基期 | 300 | 300灵石 | 3分钟 |
| 天魔战场 | 金丹期 | 2,000 | 800灵石 | 5分钟 |
| 仙府遗迹 | 元婴期 | 15,000 | 2,000灵石 | 10分钟 |
| 虚空战场 | 化神期 | 100,000 | 5,000灵石 | 15分钟 |

### 随机事件

- 游戏过程中每3~7分钟随机触发一次
- 8种事件：路遇老者、发现宝箱、云游商人、顿悟天机、拜师者、灵泉涌现、遇到劫匪、算命先生
- 每个事件有2~3个选择，不同选择有不同结果
- 结果包括：获得/损失资源、获得灵宠/法宝/丹药、道韵增长等
- 增加游戏的趣味性和不可预测性

### 转世重修

- 当累计修为足够时可转世
- 转世获得道韵 = floor(sqrt(累计修为 / 10000))
- 转世重置：修为、灵石、功法、弟子、丹药、法宝、历练
- 转世保留：道韵（永久+1%全产出/点）
- 转世后因道韵加成，修炼速度更快

### 每日签到

- 每天登录可签到一次，7天为一个循环
- 连续签到不断签，第7天奖励最丰厚
- 断签后从第1天重新开始

| 天数 | 奖励 |
|------|------|
| 第1天 | 200灵石 |
| 第2天 | 500修为 |
| 第3天 | 500灵石 |
| 第4天 | 随机丹药x1 |
| 第5天 | 1000灵石 |
| 第6天 | 2道韵 |
| 第7天 | 随机法宝x1 |

### 日常任务

- 每天刷新6个日常任务，完成后领取灵石奖励
- 任务进度实时追踪，达成后可领取
- 每日0点自动重置

| 任务 | 目标 | 奖励 |
|------|------|------|
| 打坐修炼 | 打坐20次 | 100灵石 |
| 突破境界 | 突破1次 | 200灵石 |
| 修炼功法 | 升级功法5次 | 150灵石 |
| 外出历练 | 完成1次历练 | 200灵石 |
| 服食丹药 | 使用3颗丹药 | 150灵石 |
| 招募弟子 | 招募1名弟子 | 100灵石 |

### 丹药合成

- 在丹药页底部的"丹炉合成"区域操作
- 消耗3颗同类丹药，合成1颗**强化版**
- 强化版效果翻倍（Buff类持续时间不变，即时类数值翻倍）
- 适合丹药囤积较多时使用

### 多存档系统

游戏启动时显示存档选择界面，支持 **3个存档槽位**：

- 每个槽位独立存储，互不影响
- 空槽位点击即可新建存档
- 已有存档显示：境界、修为、灵石、道韵、游戏时长、最后保存时间
- 每个槽位有"加载"和"删除"按钮
- 游戏中自动保存到当前槽位

### 本地文件夹存储

除了浏览器 localStorage，还支持将存档保存到**本地文件夹**：

1. 启动界面点击"设置存档目录"
2. 选择一个文件夹并授权（使用 File System Access API）
3. 授权后每次自动存档会同时写入该文件夹下的 `存档1.json` / `存档2.json` / `存档3.json`
4. 即使清理浏览器缓存，本地文件中的存档也不会丢失
5. 需要 Chrome / Edge 浏览器支持，其他浏览器降级为仅 localStorage

#### 导出/导入存档

- **导出**：游戏内点击"导出存档"，下载当前存档为 JSON 文件
- **导入**：启动界面或游戏内点击"导入存档"，选择 JSON 文件加载
- 导入会导入到第一个空槽位，可选择覆盖

#### 离线收益

- 关闭游戏后再次打开，自动计算离线期间产出
- 最多计算8小时离线收益
- 弹窗显示离线时长和收益，点击领取

- 超过1.5秒未点击，连击重置
- 每5连击在日志中提示

## 数值公式

### 每秒修为产出

```
修为/秒 = (基础修为 + 功法修为加成 + 法宝修为加成)
        × (1 + 境界修为加成)
        × (1 + 弟子数 × 0.05)
        × (1 + 道韵 × 0.01)
        × (1 + Σ修为Buff值)
```

### 每秒灵石产出

```
灵石/秒 = (基础灵石 + 功法灵石加成 + 法宝灵石加成)
        × (1 + 境界灵石加成)
        × (1 + 弟子数 × 0.03)
        × (1 + 道韵 × 0.01)
        × (1 + Σ灵石Buff值)
```

### 打坐收益

```
打坐收益 = (2 + 修为/秒 × 2.0 × (1 + 0~0.5随机)) × 连击倍率
连击倍率 = min(1 + 连击数 × 0.1, 3.0)
```

### 突破费用

```
突破所需修为 = 境界基础修为 × 境界倍率^(当前层数-1)
```

### 功法升级费用

```
升级费用 = 基础费用 × 费用倍率^当前等级
```

### 转世道韵

```
获得道韵 = floor(sqrt(累计修为 / 10000))
```

## 配置说明

所有游戏数值集中在 `js/game.js` 顶部的 `CONFIG` 对象中，便于调整平衡：

```javascript
CONFIG = {
    realms: [...],        // 境界配置
    upgrades: [...],      // 功法配置
    pills: [...],         // 丹药配置
    artifactTypes: [...], // 法宝类型
    artifactQualities:[], // 法宝品质
    adventures: [...],    // 历练地点
    adventureEvents:[...],// 奇遇事件
    achievements: [...],  // 成就列表
    baseCultivation: 1.5, // 基础修为产出
    baseStone: 0.8,       // 基础灵石产出
    // ...更多配置
}
```

修改 CONFIG 中的数值即可调整游戏平衡，无需改动逻辑代码。

## 架构设计

### 代码结构

```
xiuxian-idle/
├── index.html      # 页面结构
├── css/
│   └── style.css   # 样式（修仙风格深色主题）
├── js/
│   └── game.js     # 全部游戏逻辑
├── assets/         # 资源目录（预留）
└── README.md       # 本文档
```

### 逻辑分层

```
CONFIG 配置层 → 所有数值集中管理
    ↓
gameState 状态层 → 纯数据，可序列化
    ↓
计算函数层 → 纯逻辑，不依赖DOM，可移植到服务端
    ↓
操作函数层 → 改变状态的动作（突破/购买/使用等）
    ↓
UI渲染层 → 根据状态更新DOM
    ↓
游戏循环 → 定时tick驱动产出和UI更新
```

### 为联机/Steam预留

- 纯逻辑与UI分离，计算函数可移至服务端
- gameState 可序列化为 JSON，便于网络同步
- 存档系统已抽象，可替换为 Steam 云存档
- 成就系统可对接 Steam 成就
- 后续可用 Electron 打包为桌面应用上架 Steam
