# 修仙挂机录

> 一款武侠修仙题材的纯放置挂机游戏。挂机为主，辅以丹药、法宝、灵宠、阵法、历练、秘境等丰富养成系统，支持离线收益、转世重修、多存档、锁屏保护。

## 快速开始

1. 用浏览器直接打开 `index.html` 即可开始游戏
2. 纯前端运行，无需安装依赖、无需联网
3. 游戏自动存档，关闭后再次打开可继续（含离线收益）

### 运行环境

- 任意现代浏览器（Chrome / Edge / Firefox / Safari）
- 推荐 PC 端宽屏体验（1280px 以上）
- 本地文件夹存档需 Chrome / Edge 支持 File System Access API

## 核心玩法循环

```
挂机自动产出修为/灵石
        ↓
升级功法、招募弟子 → 提升产出效率
        ↓
修为攒满 → 突破境界 → 解锁新功法/丹药/阵法
        ↓
炼丹炼器、布置阵法、培养灵宠 → 进一步加速
        ↓
历练探险、秘境挑战 → 获得稀有资源
        ↓
服用丹药 → 临时爆发加速
        ↓
进度变慢时 → 转世重修 → 获得道韵永久加成 → 循环加速
```

**设计目标**：每天挂机约6小时，约13天到达金丹期，一个月左右到达元婴，节奏缓慢有成就感。

## 系统详解

### 境界系统

共 **9大境界**，每境界 **9层**，共81个阶段。

| 境界 | 突破基础修为 | 境界倍率 | 修为加成 | 灵石加成 |
|------|-------------|---------|---------|---------|
| 练气期 | 5,000 | 1.85 | +0% | +0% |
| 筑基期 | 50,000 | 1.90 | +30% | +30% |
| 金丹期 | 500,000 | 2.00 | +80% | +80% |
| 元婴期 | 5,000,000 | 2.10 | +200% | +200% |
| 化神期 | 50,000,000 | 2.20 | +500% | +500% |
| 炼虚期 | 500,000,000 | 2.30 | +1200% | +1200% |
| 合体期 | 5,000,000,000 | 2.40 | +3000% | +3000% |
| 大乘期 | 50,000,000,000 | 2.50 | +7500% | +7500% |
| 渡劫期 | 500,000,000,000 | 2.60 | +20000% | +20000% |

- 每层所需修为 = 基础修为 × 境界倍率^(当前层数-1)
- 9层圆满后点击「突破」进入下一境界，有失败概率（练气0%→渡劫+20%）
- 突破失败损失30%当前突破修为

#### 境界特权

每个境界解锁一个永久被动效果，突破后低境界特权永久累加：

| 境界 | 特权 | 效果 |
|------|------|------|
| 筑基期 | 离线收益+10% | 闭关收获额外+10% |
| 金丹期 | 炼丹成功率+5% | 炼丹失败率降低 |
| 元婴期 | 炼器成功率+5% | 炼器失败率降低 |
| 化神期 | 灵宠槽+1 | 解锁副灵宠出战位（50%效果） |
| 炼虚期 | 法宝槽+1 | 解锁第4个法宝装备位 |
| 合体期 | 突破成功率+10% | 境界突破更稳 |
| 大乘期 | 全产出+10% | 修为灵石永久+10% |
| 渡劫期 | 转世道韵+50% | 转世获得更多道韵 |

### 挂机产出

| 资源 | 基础产出 | 用途 |
|------|---------|------|
| 修为 | 1.5/秒 | 境界突破 |
| 灵石 | 0.8/秒 | 升级功法、招募弟子、购买丹药、炼丹炼器、布置阵法 |

产出加成来源：功法（固定值）、境界（百分比）、弟子分工（百分比）、法宝（固定值+词条百分比）、灵宠（百分比+技能）、阵法（百分比+等级）、道韵（百分比）、丹药Buff（临时百分比）、称号（百分比）、境界特权（百分比）、法宝灵宠羁绊（百分比）、周末/双倍日事件（百分比）。

### 功法与弟子

#### 功法（10种）

消耗灵石升级，提供固定数值产出加成，随境界解锁。功法拥有**突破**、**精通**等深度养成维度。

| 功法 | 效果类型 | 解锁境界 | 基础效果 | 品阶成长 |
|------|---------|---------|---------|---------|
| 基础吐纳术 | 修为 | 练气 | 0.4/秒 | ×1.02/级 |
| 聚灵阵 | 灵石 | 练气 | 0.25/秒 | ×1.02/级 |
| 龟息吐纳法 | 修为 | 筑基 | 2/秒 | ×1.025/级 |
| 灵田开垦 | 灵石 | 筑基 | 1.5/秒 | ×1.025/级 |
| 心法要诀 | 全属性 | 筑基 | 2.5/秒 | ×1.03/级 |
| 炼丹之术 | 全属性 | 金丹 | 5/秒 | ×1.03/级 |
| 炼器之术 | 全属性 | 金丹 | 12/秒 | ×1.035/级 |
| 周天星斗阵 | 修为 | 元婴 | 60/秒 | ×1.035/级 |
| 御剑之术 | 灵石 | 元婴 | 40/秒 | ×1.035/级 |
| 悟道心得 | 全属性 | 化神 | 175/秒 | ×1.04/级 |

**功法效果公式**：基础效果 × 等级 × 品阶成长^等级 × 突破倍率

##### 功法突破

- 每10级可突破一次（10级/20级/30级…），最多突破5次
- 每次突破效果+20%，消耗递增
- 突破需当前等级未达功法上限

##### 功法精通

- 功法满级后可精通，消耗大量灵石
- 精通后获得永久加成（修为类+3%修为产出，灵石类+3%灵石产出，全属性类各+2%）
- 精通加成全局生效，转世保留

#### 功法组合

同时升级特定功法组合可激活额外加成，在功法页底部显示。

#### 弟子

- 消耗灵石招募，基础费用80灵石，每招一名费用×1.35
- 最多招募50名
- **弟子分工**：可将弟子分配至4个方向，各提供不同加成：
  - 炼丹房：每人+1%炼丹成功率
  - 炼器房：每人+1%炼器成功率
  - 灵田：每人+0.8%灵石产出
  - 巡山：每人+0.8%修为产出（含历练奖励）
- 未分配弟子每人提供+0.5%修为、+0.3%灵石
- 转世保留半数弟子

### 丹药系统

共 **8种丹药**，分临时Buff和立即获得两类，均有每日服用上限。

| 丹药 | 效果 | 持续 | 价格 | 每日上限 |
|------|------|------|------|---------|
| 聚气丹 | 修为+100% | 5分钟 | 300 | 3 |
| 聚灵符 | 灵石+100% | 5分钟 | 300 | 3 |
| 悟道丹 | 立即获得30秒修为 | - | 250 | 5 |
| 点石成金符 | 立即获得60秒灵石 | - | 250 | 5 |
| 双倍修为丹 | 修为+200% | 3分钟 | 800 | 2 |
| 聚财符 | 灵石+200% | 3分钟 | 800 | 2 |
| 混元丹 | 修为灵石各+80% | 10分钟 | 2,500 | 1 |
| 回春丹 | 恢复50%最大生命 | - | 300 | 5 |

**服用规则**：
- 每种丹药每日上限独立，次日重置
- **同类型Buff互斥**：需等当前效果结束才能服用下一个同类丹药
- 强化版丹药（丹炉合成）效果翻倍，每日限制与普通版独立

### 炼丹与丹炉合成

#### 炼丹炉

- 消耗灵石和时间自行炼丹，比直接购买更划算
- 可设置批量炼制数量：x1 / x5 / x10 / x20 / x50
- **同时只能炼制一种丹药**，有全局冷却（8-30秒）
- 炼丹之术功法等级影响炼丹效率

#### 丹炉合成

- 消耗3颗同类丹药 → 合成1颗**强化版**（效果翻倍）
- 强化版丹药有独立的每日服用上限

### 法宝系统

#### 炼器炉

- 消耗灵石炼制随机法宝，分4档品质
- 可批量炼器（x1/x5/x10/x20/x50），同时只能炼一种品质
- 成功率：凡品90%、良品70%、上品50%、极品30%

| 品质 | 消耗灵石 | 冷却 |
|------|---------|------|
| 凡品 | 100 | 12秒 |
| 良品 | 300 | 18秒 |
| 上品 | 800 | 25秒 |
| 极品 | 2,500 | 35秒 |

#### 装备与词条

- 基础 **3个装备槽位**，炼虚期特权解锁第4槽
- 良品以上法宝携带1-2条随机词条（修为%/灵石%/生命%/战力%/固定值）
- 同类型法宝2件+10%、3件+25%套装加成
- **法宝灵宠羁绊**：特定法宝+灵宠组合提供额外加成（6组）
- 法宝提供战力和属性加成，是秘境挑战的关键

### 灵宠系统

- 通过历练、秘境、奇遇获得灵宠
- 灵宠分5种类型（火狐/玄龟/仙鹤/白虎/青龙），各有独特技能
- 消耗灵石升级灵宠提升加成
- **主灵宠**提供100%效果，**化神期解锁副灵宠**提供50%效果
- 灵宠技能影响历练和秘境（成功率/掉率/耗血/时间等）
- 灵宠图鉴记录收集进度，集齐特定组合激活羁绊

### 阵法系统

共 **5种阵法**，提供限时全局增益，**同时只能生效一个**（激活新阵法替换旧的）。

| 阵法 | 基础效果 | 外出加成 | 消耗 | 持续 |
|------|---------|---------|------|------|
| 聚灵阵 | 修为+15% | 历练修为+20% | 1,000 | 30分钟 |
| 聚财阵 | 灵石+15% | 历练灵石+20% | 1,000 | 30分钟 |
| 护山大阵 | 修为灵石各+10% | 秘境耗血-30% | 2,000 | 30分钟 |
| 周天星斗阵 | 修为+35% | 法宝掉率+15% | 6,000 | 30分钟 |
| 混元无极阵 | 修为灵石各+30% | 全外出+15% | 10,000 | 30分钟 |

- 阵法可升级最高5级，每级效果+20%（基础和外出加成同步提升）
- 阵法过期时修炼日志提醒

### 历练与秘境

#### 历练

- 选择地点派遣探险，消耗时间自动完成
- 奖励：灵石、修为、法宝、灵宠等
- 离线期间历练继续进行，自动结算

#### 秘境挑战

- 消耗生命值挑战秘境，获得丰厚奖励
- 秘境难度递增，需要足够战力和生命值
- 生命值每秒自动恢复，回春丹可快速回复
- 挑战失败不扣血，但无法获得奖励

### 奇遇事件

- 每 **30-60分钟** 随机触发一次
- 每天最多 **5个** 奇遇，支持累计（弹窗打开时新事件入队）
- 奇遇包含选择分支，不同选择有不同结果
- 可能获得稀有资源、道韵、灵宠等

### 活动中心

#### 每日签到

- 每天签到一次，点击弹框显示奖励
- 7天为一个循环，奖励随境界提升（每阶×3倍）

#### 日常任务

- 每天刷新3个任务（升级功法、炼器、招募弟子等）
- 完成领取奖励，奖励随境界缩放

#### 成就系统

- 达成特定条件解锁成就，获得道韵奖励
- 成就点数可在成就商店兑换稀有物品

#### 称号系统

- 达成里程碑自动获得称号，提供永久属性加成

### 转世重修

- **最低境界要求：筑基期**（练气期无法转世）
- 转世获得道韵 = max(3, floor(sqrt(累计修为 / 5000)))，渡劫期特权+50%
- 道韵永久提升修为和灵石产出，转世不重置
- 转世重置：修为、灵石、功法等级、丹药、阵法、弟子分工
- 转世保留：道韵、成就、称号、功法突破/精通、最高品质法宝1件、最高品质灵宠1只、半数弟子
- 前期保底3点道韵，鼓励在进度变慢时转世

### 战力与生命值

- **战力**：由境界、法宝、灵宠、阵法等综合决定，影响秘境挑战
- 顶部显示战力数值，点击可查看战力详情拆解
- **生命值**：秘境挑战时扣血，每秒自动恢复
- 回春丹可立即恢复50%最大生命

### 锁屏保护

- 可设置锁屏密码，点击底部「锁屏」按钮锁定游戏
- 支持自动锁屏（无操作1/3/5/10/30分钟后自动锁定）
- **刷新页面后保持锁定状态**（sessionStorage持久化）
- 锁屏期间游戏继续后台挂机
- 未设置密码无法使用锁屏功能

### 多主题切换

在「设置」中可切换7种界面主题：

| 主题 | 色调 |
|------|------|
| 金色 | 默认暖金 |
| 青冥 | 青色系 |
| 紫霞 | 紫色系 |
| 碧波 | 蓝色系 |
| 翠林 | 绿色系 |
| 赤炎 | 红色系 |
| 暗夜 | 纯暗灰 |

主题偏好随存档保存，所有边框、文字、背景、光晕同步变色。

## 存档系统

### 多存档槽位

- 启动界面显示 **3个存档槽位**，独立存储互不影响
- 每个槽位显示：境界、修为、灵石、道韵、游戏时长、最后保存时间
- 支持加载、删除、新建存档

### 存储方式

- **默认**：浏览器 localStorage，存档标识 `xiuxian_idle_save_v3_slot_X`
- **可选**：本地文件夹存储（File System Access API），授权后自动写入 JSON 文件
- 在「设置」中可查看当前存档位置信息
- ⚠ 清除浏览器数据会丢失 localStorage 存档，建议定期导出备份

### 导入/导出

- 导出：下载当前存档为 JSON 文件
- 导入：选择 JSON 文件加载到空槽位

### 离线收益

- 关闭游戏后自动计算离线产出
- 最长离线 **48小时**，离线效率 **50%**
- 再次打开时弹窗显示离线时长和收益，点击领取

## 数值公式

### 每秒修为产出

```
修为/秒 = (基础修为 + 功法修为加成 + 法宝修为加成)
        × (1 + 境界修为加成)
        × (1 + 弟子数 × 0.015)
        × (1 + 灵宠修为加成)
        × (1 + 阵法修为加成)
        × (1 + 道韵 × 道韵加成)
        × (1 + 称号加成)
        × (1 + Σ修为Buff值)
```

### 每秒灵石产出

```
灵石/秒 = (基础灵石 + 功法灵石加成 + 法宝灵石加成)
        × (1 + 境界灵石加成)
        × (1 + 弟子数 × 0.01)
        × (1 + 灵宠灵石加成)
        × (1 + 阵法灵石加成)
        × (1 + 道韵 × 道韵加成)
        × (1 + 称号加成)
        × (1 + Σ灵石Buff值)
```

### 突破所需修为

```
突破修为 = 境界基础修为 × 境界倍率^(当前层数 - 1)
```

### 功法效果

```
功法效果 = 基础效果 × 等级 × 品阶成长^等级
```

### 转世道韵

```
获得道韵 = max(3, floor(sqrt(累计修为 / 5000)))
```

### 签到/任务奖励缩放

```
奖励倍率 = 1 + 境界索引 × 3
```

```
│   ├── core.js         # 核心计算 + 游戏操作（突破/升级/招募/转世）
│   ├── gameplay.js     # 玩法系统（丹药/法宝/历练/灵宠/炼丹/阵法/秘境/奇遇）
│   ├── storage.js      # 存档系统（保存/加载/离线/导入导出/多槽位）
│   ├── ui.js           # 界面渲染 + 玩法说明 + 主题切换
│   ├── lock.js         # 锁屏与设置
│   └── main.js         # 初始化 + 游戏主循环 + 事件绑定
└── README.md           # 本文档
```

### 逻辑分层

```
config.js  配置层 → 所有数值集中管理
    ↓
state.js   状态层 → gameState纯数据，可序列化
    ↓
core.js    计算层 → 纯逻辑，不依赖DOM
    ↓
gameplay.js 操作层 → 改变状态的动作
    ↓
ui.js      渲染层 → 根据状态更新DOM
    ↓
main.js    循环层 → gameTick驱动产出和UI更新
```

### v3.1.2（当前版本）— 移除功法顿悟

### v3.1.1 — 功法系统精简

**移除系统：**
- 移除功法**品阶系统**（5阶品阶/等级上限/效果倍率）
- 移除功法**熟练度系统**（领悟获得熟练度/每级+5%效果）
- 移除功法**推演进阶**（满级推演升阶/成功率/冷却）
- 移除**修炼分配**（全修炼/半修炼半领悟/全领悟三档切换）
- 功法效果公式简化为：基础效果 × 等级 × 品阶成长^等级 × 突破倍率
- 功法等级上限恢复为原始配置（不再受品阶限制）
- 离线收益恢复为纯修为/灵石产出（不再有离线领悟）

**保留系统：**
- 功法突破（每10级突破，+20%效果，最多5次）
- 功法精通（满级精通，永久加成）
- 功法顿悟（10倍成本直接升级，5分钟冷却）
- 功法组合（同时升级特定组合激活额外加成）

**存档兼容：**
- 旧存档中的品阶/熟练度/修炼分配数据自动忽略，不影响游戏运行

### v3.1.0 — 功法系统大升级与Bug修复

**功法系统大升级：**
- **品阶系统**：每种功法分5阶（凡品→良品→上品→极品→仙品），品阶越高等级上限和效果倍率越高（凡品50级×1.0 → 仙品200级×3.0）
- **熟练度系统**：通过修炼分配中的"领悟"获得熟练度，每10点升1级共10级，每级效果+5%（最高+50%）
- **推演进阶**：当前品阶满级+熟练度满级后可推演升阶，消耗递增灵石，有成功率（80%→20%），失败不扣熟练度但300秒冷却，成功后品阶+1等级重置
- **修炼分配**：打坐修炼可分配比例（全修炼/半修炼半领悟/全领悟），领悟增加功法熟练度，全领悟模式保留50%修为产出不会卡关
- **功法效果公式**重构：基础效果 × 等级 × 品阶成长^等级 × 突破倍率 × 品阶倍率 × 熟练度倍率
- 离线收益应用修炼分配和离线领悟

**Bug修复（6项）：**
1. 修复功法卡片内容显示不完整问题（修炼分配栏移出grid容器，功法页改为整体滚动，卡片紧凑布局）
2. 修复功法精通条件与品阶系统冲突（精通条件改用当前品阶上限而非原始200级）
3. 修复升级预览数值不准确（预览包含品阶/熟练度/突破全部倍率）
4. 明确转世后品阶/熟练度/突破/精通保留，更新转世确认提示
5. 修复全领悟模式修为产出为0导致卡关（统一使用getEffectiveCultivationGain，最多扣50%修为）
6. 修复突破功能与品阶上限交互（突破条件改用当前品阶上限）

**体验优化：**
- 功法卡片紧凑布局：效果+花费同行，按钮2列网格，信息密度更高
- 功法页整体可滚动，所有卡片和弟子堂完整展示
- 修炼分配栏独立于功法卡片网格，避免布局冲突

**存档兼容：**
- 所有新增状态字段（upgradeTiers/upgradeProficiency/cultivationAllocation/selectedInsightUpgrade/evolveCooldowns）自动迁移默认值，旧存档可直接读取

### v3.0.0 — 系统深度联动与数值重构

**新增系统：**
- **境界特权系统**：9个境界各解锁一个永久被动效果（筑基离线+10%、金丹炼丹+5%、元婴炼器+5%、化神灵宠槽+1、炼虚法宝槽+1、合体突破+10%、大乘全产出+10%、渡劫转世道韵+50%），突破后低境界特权永久累加
- **弟子分工系统**：弟子可分配至炼丹房/炼器房/灵田/巡山4个方向，各提供不同加成（成功率/灵石/修为），未分配弟子提供微量双修加成
- **法宝词条系统**：良品以上法宝携带1-2条随机词条（修为%/灵石%/生命%/战力%/修为固定/灵石固定），影响产出计算
- **灵宠技能系统**：每种灵宠拥有独特技能（火狐秘境成功率+10%、玄龟秘境耗血-30%、仙鹤历练时间-15%、白虎法宝掉率+20%、青龙全历练+20%），支持多效果

- **阵法升级系统**：阵法可升级最高5级，每级效果+20%，升级同时影响基础产出和外出加成
- **功法顿悟系统**：消耗10倍升级成本直接升1级，5分钟全局冷却，回收后期溢出灵石
- **法宝灵宠羁绊**：6组法宝+灵宠组合提供额外加成（飞剑+火狐修为+10%等）
